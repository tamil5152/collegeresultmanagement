# Portfolio

A fast, dependency-free personal portfolio (HTML + CSS + JS) with dark/light mode.

## Customise
Search `index.html` for `TODO` and replace the placeholder text, links and projects with your own.

## Preview locally
```bash
cd portfolio && python3 -m http.server 8000
```

## Deploy (GitHub Pages)
Move this folder into its own repo (e.g. `tamil5152.github.io`), then enable
**Settings → Pages → Deploy from branch → main / root**.
